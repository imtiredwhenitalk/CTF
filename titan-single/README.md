# Operation Titan — один сайт

Платформа (реєстрація, здача флагів, скорборд) + 10 вразливих завдань в одному Flask-додатку, один контейнер, один порт.

```bash
docker compose up -d --build
```
Сайт: http://localhost:8000  (порт змінюється в `docker-compose.yml`). Зупинити старий стек: `docker compose down` у його папці.

Скинути всі акаунти й рішення: `docker compose down -v`.

| # | Завдання | Вразливість |
|---|---|---|
| 1 | /c/1/ | витік `.git` на веб-сервері + XOR |
| 2 | /c/2/ | JWT: підміна алгоритму RS256→HS256 |
| 3 | /c/3/ | слабкий LFSR (known-plaintext, 16-бітний seed) |
| 4 | /c/4/ | pickle-десеріалізація + слабкий HMAC-ключ |
| 5 | /c/5/ | JWT зі слабким секретом + RSA з малим N |
| 6 | /c/6/ | AES-ECB: склеювання блоків у cookie |
| 7 | /c/7/ | blind SQLi з обходом WAF |
| 8 | /c/8/ | RSA, атака Вінера |
| 9 | /c/9/ | ZIP у PNG, пароль-підказка |
| 10 | /c/10/ | LFI (обхід фільтру `..` абсолютним шляхом) |

⚠️ Тільки для навчання, не виставляйте в інтернет. Усі завдання в одному процесі, тому RCE у №4 дає доступ до всього сайту (у тому числі до флагів інших завдань) — для змагань із чесним заліком краще окремі контейнери, як у попередній версії.
