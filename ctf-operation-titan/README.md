# Operation Titan: Final Edition 🛡️

Повна інфраструктура з 10 завданнями, вбудованим OpenVPN та **виправленим автоматичним налаштуванням CTFd**.

## 🚀 Що виправлено у цій версії:
- **CTFd Auto-Setup:** Виправлено баг із регулярним виразом для токена `csrfNonce`. Тепер платформа на 100% налаштовується автоматично (реєструє адміна, створює таски, прописує прапори).
- **Бази даних:** Скрипт коректно відпрацьовує на нових версіях CTFd.

## 🛠 Запуск
Оскільки попередній запуск міг створити "зламану" (недоналаштовану) базу даних, **обов'язково** очистіть старі томи перед запуском:
```bash
docker compose down -v
chmod +x setup.sh
./setup.sh
```
Після старту:
- **CTFd:** `http://localhost:8000` (Вже налаштовано! Логін `admin`, пароль `admin`)
- **VPN Портал:** `http://localhost:5050`
