# Writeup: Flag 10 - Docs Escape (Path Traversal / LFI)

1. Відкрити `http://localhost:8090`. Портал показує список документів, які відкриваються через `GET /view?file=<ім'я>`.
2. У HTML-коментарі та у `changelog.txt` є підказки: чутливі файли лежать у каталозі `secret/` поруч з `docs/`, облікові дані - у `secret/vault.txt`; також згадано «захист від ../».
3. Спробувати `GET /view?file=../secret/vault.txt` - не працює: код видаляє підрядок `../`.
4. Фільтр працює за **один прохід** (`name.replace("../", "")`), тому його можна обійти вкладеною послідовністю. З `....//` після видалення вставленого `../` лишається `../`:
   `curl 'http://localhost:8090/view?file=....//secret/vault.txt'`
5. Абсолютні шляхи (`/etc/passwd`) не спрацюють, бо код відрізає початковий `/`, тож обхід саме через `....//`.
6. Отримати прапор: `CTF{p4th_tr4v3rs4l_f1lt3r_0nly_run5_0nc3_6029}`.

## Виправлення (для звіту)
Не фільтрувати рядок, а нормалізувати шлях і перевіряти, що він лишається всередині дозволеного каталогу:
```python
path = os.path.realpath(os.path.join(DOCS_DIR, name))
if not path.startswith(os.path.realpath(DOCS_DIR) + os.sep):
    abort(403)
```
Або віддавати лише файли з білого списку.
